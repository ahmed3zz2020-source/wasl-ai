## هذا المستودع إيه؟

المصدر الوحيد للحقيقة للمشروع. كل حاجة بتتعمل في المشروع — بنية، كود، قرارات، بروميتات، مراجعات — بتتسجّل هنا.
السبب: بيئة التشغيل بتتصفّر، والشات بيتغيّر. اللي في GitHub ما بيضيعش.

## القراءة السريعة (لأي شات جديد)

```bash
cd /workspace/wasl-ai
cat STATUS.md          # فين وقفنا بالظبط — ابدأ هنا
cat CHARTER.md         # المشروع إيه وليه
cat PROTOCOL.md        # إزاي بنشتغل مع بعض
cat ARCHITECTURE.md    # البنية المقترحة
tail -40 SESSION-NOTES.md
```

لو شات جديد: **ابدأ بـ `STATUS.md` وبعدين `PROTOCOL.md`**. ده كل المطلوب عشان تفهم المشروع وتكمل.

## الخريطة

| الملف | إيه اللي فيه |
|---|---|
| `STATUS.md` | لوحة الحالة — آخر تحديث، اتعمل إيه، الجاي إيه، إيه المتبقي |
| `CHARTER.md` | ميثاق المشروع: الهدف، السوق، النموذج، معايير النجاح |
| `PROTOCOL.md` | بروتوكول الشغل: دورة البروميت، بوابات الموافقة، تدقيق الأدوات |
| `ARCHITECTURE.md` | المعمارية — تُبنى تدريجياً من بروميتات ChatGPT |
| `DECISIONS.md` | سجل القرارات — كل قرار مع سببه |
| `SESSION-NOTES.md` | يوميات الشغل |
| `AGENTS.md` | عقد الوكلاء — من يعمل إيه |
| `PROMPTS/` | بروميتات ChatGPT كما وصلت، مرقّمة |
| `REVIEWS/` | حزم المراجعة الجاهزة للنسخ لـ ChatGPT + ردودنا على ملاحظاته |
| `research/` | أبحاث السوق والمنافسين (بأرقام ومصادر) |
| `logs/` | سجل يومي |
| `docs/` | وثائق مرافقة |
| `dashboard/` | مصدر اللوحة الدائمة (اللي على workers.dev) |
