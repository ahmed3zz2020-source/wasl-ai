## اللوحة الدائمة

**https://wasl-hub.ahmed3zz2020.workers.dev**

لينك واحد فيه كل حاجة. بتقرأه من موبايلك أو تابلتك، وبتفضل محفوظ طول عمر المشروع.

| المسار | إيه اللي فيه |
|---|---|
| `/bridge` | **حزمة السياق الكامل** — اللي ChatGPT بيقرأ منه |
| `/review/latest` | آخر حزمة مراجعة (للنسخ أو للقراءة) |
| `/p/…` | أي ملف من ملفات المشروع بصيغة صفحة |
| `/api/state` | حالة المشروع JSON |

> ⭐ اللوحة بتقرأ من GitHub **لحظتها** ⇒ كل commit بيتحدّث من غير نشر.

## الدايرة مع ChatGPT

```
ChatGPT (مهندس معماري)          أنا (منفّذ)              المالك (يقرّر)
        │                            │                          │
        │  يقرأ /bridge ────────────►│                          │
        │                            │                          │
        │  يطلّع بروميت ─────────────┼──────► يبعتّه لي ──────►│
        │                            │                          │
        │                            │◄──── موافقة ─────────────│
        │                            │  ينفّذ + يقيس            │
        │                            │                          │
        │  يراجع /review/latest ◄────┼────── يبعت الحزمة ─────►│
        │                            │                          │
        │  يطلّع ملاحظات ────────────┼────── يبعتهم لي ────────►│
        │                            │  ينفّذ المؤكد            │
```

**الأدوار واضحة**: ChatGPT بيصمّم · أنا بنفّذ · أنت بتقرّر.
التفاصيل والصيغة الإلزامية: [`CHATGPT-BRIDGE.md`](CHATGPT-BRIDGE.md)
