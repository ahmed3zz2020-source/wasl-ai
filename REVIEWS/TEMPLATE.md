# قالب حزمة المراجعة — WASl AI

> ⛔ **انسخ هذا الملف** لكل حزمة جديدة على شكل `REVIEWS/RNNN-<الموضوع>.md`
> ⛔ **والنسخة القصيرة** على شكل `REVIEWS/RNNN-<الموضوع>.short.md` (٦٠٠ حرف)
> ⛔ الأقسام **السبعة** بالترتيب ده إلزامية — عشان ChatGPT يراجع النقطة الصح.

---

## ١. الرأس

```
حزمة مراجعة: RNNN
التاريخ: YYYY-MM-DD
الحالة: [مسودة / جاهزة للمراجعة / اتراجع عليها]
البروميت المصدر: PROMPTS/RNNN-<الموضوع>.md
المرحلة: [رقم واسم المرحلة من TIMELINE.md]
```

## ٢. إيه اللي اتعمل

> ⚠️ **كل بند لازم يكون معاه دليل.** «كتبت الكود» مش دليل.
> ⚠️ **كل رقم لازم يكون معاه مصدر.**

```
## RNNN.1 — <اسم العنصر>
**الحالة**: ✅ جاهز | ⏳ جزئي | ❌ متعطّل
**الدليل**: <لينك حيّ | command شغّال | لقطة>
**القياس**: <رقم + مصدره>
**ملاحظة**: <لو فيه حاجة مهمة>
```

## ٣. قرارات اتخدت

```
## RNNN-D1 — <القرار>
**السبب**: ...
**البديل اللي اترك**: ... — رُفض: ...
**أثره**: ...
```

## ٤. حاجات عملتها أحسن من المقترح

> ⛔ فاضي = مفيش. ⛔ ممنوع تعمل زينة.

```
## RNNN-Δ1 — <الفرق>
**المقترح الأصلي**: ...
**اللي عملته**: ...
**ليه ده أحسن**: ...
**التكلفة**: ...
```

## ٥. نقاط محتاجة قرار من المالك

> أسئلة **محددة** — كل واحد إجابته بتغيّر شغل محدد.

```
## RNNN-Q1
**السؤال**: ...
**ليه مهم**: ...
**لو ما جاوبتش**: <الافتراضي اللي هينفَّذ>
```

## ٦. أسئلة مقترحة لـ ChatGPT

> الأسئلة دي بتوجّه المراجعة ⇒ Review أفضل في وقت أقل.

```
## RNNN-RQ1
**السؤال**: ...
**ليه مهم أعرف رأيك فيه**: ...
```

## ٧. الملفات المتغيرة

```
| الملف | إيه اللي اتغير |
|---|---|
| `path/to/file` | وصف سطر واحد |
```
