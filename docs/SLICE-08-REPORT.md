## ٣. ⭐⭐⭐ التصميم: من هي ⇒ من أين ⇒ ما يُسمح

> ⭐⭐ **المبدأ الحاكم**: ⭐ **مصدر الهوية يجيب (من هي)** ⇒ ⭐ **والقرار يجيب (يحق له)** ⇒
> ⭐⇒⇒⇒ **والاتصال بينهما = فحص واحد في النواة** (`assertCapability`) ⇒ ⭐⇒⇒⇒
> ⭐⇒⇒⇒⇒ **فلا يمكن لطبقة الهوية أن تمنح صلاحية لم يعطِها الدور.**

```
⭕  الطلب (معرّف هوية + مرجع محادثة + اسم عملية)
   │
   ▼
┌────────────────────────────────────────────────────────────┐
│ ① LocalIdentityRegistry  (من هي)                           │
│   • سجلّ هوية لكل دور  • تسجيل مرة واحدة  • إلغاء         │
│   • انتهاء صلاحية  • سلطة إدارة بنَسَب مثبت                │
└────────────────────────────────────────────────────────────┘
   │  (الدور من السجلّ · لا من الحمولة)
   ▼
┌────────────────────────────────────────────────────────────┐
│ ② مصدر الهوية المحلية  (من أين)                            │
│   • مصدر حقيقي بنطاق test  • يبني هوية جديدة من السجلّ      │
│   • يرفض هوية أدنى من دوره  • يرفض الملغاة والمنتهية       │
└────────────────────────────────────────────────────────────┘
   │  (هوية موثّقة)
   ▼
┌────────────────────────────────────────────────────────────┐
│ ③ authorizeLocalRequest  (ما يُسمح) — ٦ خطوات · مغلقة      │
│   ① شكل الطلب  ② الهوية  ③ المستأجر  ④ الدور              │
│   ⑤ بناء السياق  ⑥ صلاحية العملية                         │
└────────────────────────────────────────────────────────────┘
   │  (سياق تنفيذ)
   ▼
   عمليات النواة (قراءة · حالة · إسناد · طابور · مؤشرات)
```
