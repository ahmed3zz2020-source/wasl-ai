## ⭐ ٦. ⭐ كيف تُتحقّق من الحزمة

```bash
cd /workspace/wasl-ai

# ① اختبار المتتبّع (وحده)
node --experimental-strip-types --test tests/tools/cost-tracker.test.ts

# ② فحص لغوي لكل الوثائق
python3 tools/check-lang.py docs/ops-pilot-package

# ③ المتتبّع على القالب (يجب أن يرفض — لأنّه بلا أسعار)
node --experimental-strip-types tools/wasl-cost-tracker.ts \
  --config docs/ops-pilot-package/cost-config.example.json ; echo "exit=$?"

# ④ تكرار تمرين الاسترجاع (§٧ من restore-drill.md)
export PGHOST=/tmp PGPORT=5432 PGUSER=postgres
export PATH=/usr/lib/postgresql/15/bin:$PATH
npm run db:backup
npm run db:verify -- .local/backups/<artifact>.dump.enc
npm run db:restore -- .local/backups/<artifact>.dump.enc --target wasl_restore_drill
```

> ⭐ **ملاحظة على الخطوة ③**: ⭐ **الخروج المتوقع `1` — لا `0`** — ⭐ **لأن القالب بلا أسعار والقاعدة تقضي بألا يُختلق سعر** — ⭐ **وهذا هو الدليل على أن المتتبّع يعمل كما وُعد**.
