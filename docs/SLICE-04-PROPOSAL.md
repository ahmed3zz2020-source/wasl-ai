## ٢. ⭐ حالات المحادثة والانتقالات المسموحة

| # | ⭐ الحالة | ⭐ المعنى |
|:-:|---|---|
| ١ | ⭐ `new` | ⭐ محادثة واردة ولم تُفتح بعد |
| ٢ | ⭐ `open` | ⭐ مفتوحة — لم تُسند لأحد |
| ٣ | ⭐ `assigned` | ⭐ مسندة لموظف داخل المستأجر |
| ٤ | ⭐ `pending` | ⭐ بانتظار معلومة/ردّ (معلّقة داخل النطاق) |
| ٥ | ⭐ `resolved` | ⭐ حُلّت — بانتظار الإغلاق |
| ٦ | ⭐ `closed` | ⭐ مغلقة (أرشيف — ⛔ بلا عودة) |

**⭐ الانتقالات المسموحة (قائمة مغلقة — أي انتقال آخر مرفوض):**

| ⭐ من | ⭐ إلى | ⭐ الشرط |
|---|---|---|
| `new` | `open` | ⭐ ⭐ |
| `open` | `assigned` | ⭐ **بلا إسناد ⇒ لا انتقال** (الإسناد شرط لا أثر جانبي) |
| `open` | `pending` | ⭐ ⭐ |
| `open` | `resolved` | ⭐ ⭐ |
| `assigned` | `open` | ⭐ إلغاء الإسناد |
| `assigned` | `pending` | ⭐ ⭐ |
| `assigned` | `resolved` | ⭐ ⭐ |
| `assigned` | `assigned` | ⭐ نقل الإسناد لموظف آخر (نفس المستأجر) |
| `pending` | `assigned` | ⭐ ⭐ |
| `pending` | `resolved` | ⭐ ⭐ |
| `resolved` | `open` | ⭐ إعادة فتح (بسبب مُسجَّل) |
| `closed` | — | ⭐ **بلا انتقال — نهائية** |

⭐ **بلا مسار افتراضي**: ⭐ أي انتقال غير مدرَّج ⇒ `reason_code` معلَن + **صفر تغيير في الحالة**.

## ٣. ⭐ الإسناد + الصلاحيات

- ⭐ **الإسناد**: ⭐ `assign(conversation_ref, assignee_actor_id)` ⇒ ⭐ **الموظف مُقيَّد بنطاق المستأجر من السياق** ⇒ ⭐ **ولا يُسنَد لموظف مستأجر آخر** ⇒ ⭐ **ولا لموظف غير موجود أصلاً** ⇒ ⭐ **والإسناد إلى محادثة لا تخص المستأجر ⇒ صفوف/حالة صفر (لا كشف وجود)**.
- ⭐ **الصلاحيات الثلاث (مفصولة)**:

| ⭐ الصلاحية | ⭐ تسمح بـ |
|---|---|
| ⭐ `conversation.state.read` | ⭐ قراءة حالة المحادثة ومُسنَدها |
| ⭐ `conversation.state.update` | ⭐ تغيير الحالة (بانتقالات مسموحة فقط) |
| ⭐ `conversation.assign` | ⭐ الإسناد ونقله وإلغاؤه |

⭐ **والافتراضي = المنع** (جلسة بلا صلاحيات ⇒ لا قراءة ولا تعديل ولا إسناد) · ⭐ **والفحص قبل أي وصول للبيانات** · ⭐ **والمحاولات المرفوضة تُوثَّق** (نمط سجل قراءات الشريحة الثالثة).

## ٤. ⭐ سجل التغييرات (التدقيق)

- ⭐ **سجل مستقل** عن سجل تدقيق المعالجة وعن سجل أحداث القراءة ⇒ ⭐ ونوع قيمة مستقل.
- ⭐ **سطر لكل تغيير**: (المستأجر · المنفّذ · العملية · من · إلى · السبب · الإسناد من/إلى · الوقت).
- ⭐ ⛔ **بلا نص رسائل · بلا أسرار · بلا بيانات حسّاسة** ⇒ ⭐ وقائمة سماح صريحة + كاشف أسرار (نمط `AUDIT_META_ALLOWLIST`).
- ⭐ **قراءة السجل معزولة بالمستأجر + الصلاحية** (`conversation.state.read`) ⇒ ⭐ **ولا `entries()` غير المعزولة في مسار القراءة**.
