## ١. ⭐ الوظيفة العملية

| # | ⭐ البند | ⭐ التفصيل |
|:-:|---|---|
| ١ | ⭐ **مركز عمل الوكيل** | ⭐ استعلام قراءة فوق `Slice 03` + `Slice 04` — يعطي قائمة محادثات مرتّبة: الحالة · المُسنَد · عدد الرسائل · زمن الانتظار · التصنيف (لي / غير مُسنَد / معلّقة / مغلقة حديثاً) |
| ٢ | ⭐ **مؤشرات الخدمة** | ⭐ عدّادات محسوبة من السجلّين: عدد المحادثات لكل حالة · زمن أول رد · زمن الحل · العبء لكل موظف |
| ٣ | ⭐ **بلا كتابة** | ⭐ قراءة فقط — لا تُنشأ حالة ولا يُسند ولا يُعدَّل سجل تغييرات — فالشريحة **لا توسّع سطح الكتابة** |
| ٤ | ⭐ **بلا محتوى رسائل** | ⭐ النتائج **لا تُعيد نصّ الرسائل** — فقط معرّفات وأرقام — حتى لا يتحوّل المؤشر إلى قناة تسريب |
| ٥ | ⭐ **عزل بالمستأجر** | ⭐ كل استعلام مقيَّد بسياق المستأجر — ولا استعلام عابر للوحدات |

## ٢. ⭐ لماذا هذه الوظيفة تحديداً (الأثر على النسخة التجريبية)

| # | ⭐ السبب | ⭐ **الأثر** |
|:-:|---|---|
| ١ | ⭐ «Customer AI» يبدأ من «ما عليّ أن أفعل الآن» | ⭐ الـqueue يجيب على هذا السؤال مباشرة — بدل قائمة محادثات مرتّبة بالإنشاء |
| ٢ | ⭐ البيانات موجودة أصلاً | ⭐ الـqueue = استعلام فوق الشريحتين ٣ و ٤ — **لا بيانات جديدة ولا نماذج جديدة** |
| ٣ | ⭐ الحالة وحدها لا تكفي | ⭐ المحادثة قد تكون `open` بلا إسناد ⇒ لا أحد يعمل عليها ⇒ **الـqueue يكشف ذلك** |
| ٤ | ⭐ لا قياس بلا مؤشرات | ⭐ زمن الحل وزمن أول رد بلا أرقام = انطباع — والمؤشرات تجعل النقاش قابلاً للاختبار |
| ٥ | ⭐ الشرائح السابقة مغلقة | ⭐ بعد `resolved` و `closed` لا مجال للتحسين — القياس هو الخطوة المنطقية التالية |
