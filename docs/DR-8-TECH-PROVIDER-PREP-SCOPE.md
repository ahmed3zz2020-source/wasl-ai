# ⭐ نطاق التحضير العملي — مسار Tech Provider + Embedded Signup (٤ نوفمبر ٢٠٢٦)

> ⭐ **مصرَّح**: ⭐ **هذا عرض تخطيطي — لا تنفيذ ولا كود ولا حساب ولا قرار.** ⭐ **والمسار نفسه لم يُعتمد من المالك ⇒ ⇒ فكل ما يلي مشروط بقراره.**
> ⭐ **القاعدة الحاكمة**: ⭐ **التحضير = كل ما يمكن بناؤه واختباره بلا حساب Meta ولا حساب مطوّر ولا طلب App Review ولا بيانات عميل حقيقية ولا تواصل خارجي ولا عقد.**

## ١. ⭐ قابل للتحضير الآن (٩ بنود — بلا حساب ولا دفع ولا موافقة)

| # | ⭐ البند | ⭐ ما يُبنى | ⭐ حدوده |
|:-:|---|---|---|
| ١ | ⭐ **عميل Cloud API (غلاف النداءات)** | ⭐ HTTP client + تعريف الاستجابات + تحويل الأخطاء + سجل أخطاء | ⭐ **بلا مفتاح ولا طلب حقيقي** |
| ٢ | ⭐ **أنواع الرسائل** | ⭐ تعريف قوالب service · utility · marketing + قوالب marketing | ⭐ **بلا أرقام تسعير (DR-11 غير معتمد)** |
| ٣ | ⭐ **هيكل Webhooks** | ⭐ تعريف الأحداث + التحقّق من التوقيع + منع التكرار + التخزين + إعادة المحاولة + سجل تدقيق | ⭐ **بلا ربط حقيقي** |

| ٨ | ⭐ **اختبارات وحدات** | ⭐ اختبارات على الكود النقي + Mock لـHTTP | ⭐ **بلا طلبات حقيقية** |
| ٩ | ⭐ **دليل تشغيل** | ⭐ نص إرشادي: فتح الحسابات · تقديم Tech Provider · تمرير App Review | ⭐ **إرشاد فقط — لا تنفيذ** |

## ٣. ⭐ حدود التحضير المقترح (لو اعتُمد)

- ⭐ **يُسمح**: كود نقي + اختبارات وحدات + Mock + وثائق + قوالب مستندات.
- ⭐ **⛔ لا يُسمح**: مفتاح API في الريبو · ربط production · نداءات حقيقية على حساب · بيانات عميل حقيقية · أي تواصل خارجي.
- ⭐ **⛔ لا يُعدّ**: موافقة المسار · اعتماد التسعير · أي بند من §٢.
