## ⭐ ٢. شكل ملف المعرفة (صارم ومعلن)

```markdown
---
title: دليل المنتج
tags: [منتج, واجهة, محادثات, تذاكر, عملاء, سجل]
updated: 2026-11-26
---

## عنوان القسم

نصّ الفقرة الأولى. وهي المقطع الأول.

نصّ الفقرة الثانية. وهي المقطع التاني.
```

⭐ **القواعد** (وكل واحدة تكسر ⇒ يُرفض الملف ويُقال مكانه وسببه):

| # | القاعدة | كود الخطأ |
|:-:|---|---|
| ١ | ⭐ السطر الأول `---` والترويسة بتتقفل | `front-matter-missing` · `front-matter-unclosed` |
| ٢ | ⭐ `title` موجود وغير فاضي | `title-missing` · `title-empty` |
| ٣ | ⭐ `tags` موجود وقائمة فيها وسم واحد على الأقل | `tags-missing` · `tags-empty` · `tags-shape` |
| ٤ | ⭐ `updated` اختياري وبالشكل `YYYY-MM-DD` | `updated-shape` |
| ⑤ | ⭐ مفتاح مجهول في الترويسة يُرفض | `front-matter-key` |
| ⑥ | ⭐ في قسم واحد على الأقل (`##`) | `no-sections` |
| ⑦ | ⭐ كل قسم له نصّ | `empty-section` |
| ⑧ | ⭐ ممنوع نصّ قبل أول قسم | `content-before-section` |
| ⑨ | ⭐ ممنوع عنوان أول `#` جوّه النصّ | `unexpected-heading` |

> ⭐ **الخطأ بيقول مكانه**: ⭐ `الملف:السطر — السبب` ⇒ ⇒ والكل الأخطاء بتتجمّع مرة واحدة (مش أول واحد بس).

## ⭐ ٤. الترجيح (`TF-IDF` مبسّط · حتمي)

| # | الجزء | القاعدة |
|:-:|---|---|
| ① | ⭐ النُدرة | `idf(t) = log(1 + N / (1 + df(t)))` ⇒ `N` = عدد المقاطع · `df(t)` = عدد المقاطع التي تحمل الكلمة |
| ② | ⭐ الرِدّة | `tf(t,c) = count(t,c) / length(c)` ⇒ طول المقطع ما بيقرّرش الغلبة |
| ③ | ⭐ العنوان حقل موازي | `title` و`section` بيدخلوا بعامل `0.6` من وزن المتن ⇒ المتن يكسب |
| ④ | ⭐ الجيب التمام | ⭐ الدرجة بين ٠ و ١ ⇒ والكلمات اللي المقطع ما حملهاش بتنقص الدرجة ⇒ ⇒ المقطع اللي جاوب نصّ السؤال بيتقدّم على اللي جاوب ربعه |
| ⑤ | ⭐ ترتيب التعادل | `file` ⇒ ثم `line` ⇒ ثم `id` ⇒ ⇒ **مفيش عشوائية** |

⭐ **الحدود المعلنة** (والمرشّح يعدّلها من غير ما يمسّ الكود):

| الحد | القيمة | معناه |
|---|---|---|
| ⭐ `topK` | `3` | كام مقطع ترجع |
| ⭐ `minScore` | `0.12` | أقل درجة مقبولة |
| ⭐ `minCoverage` | `0.6` | أقل نسبة من كلمات السؤال لازم المقطع يحملها |

⭐ **شروط الرفض** (أي واحد فيهم ⇒ «لا إجابة في الفهرس»):
1. ⭐ السؤال مفيهوش كلمة دالة.
2. ⭐ مفيش كلمة من السؤال في الفهرس أصلاً.
3. ⭐ مفيش مقطع وصل للدرجة والتغطية مع بعض.

## ⭐ ٥. كيف تُستعمل الوحدة

```ts
import { buildKnowledgeIndex } from './server/knowledge/index-builder.ts';
import { retrieve } from './server/knowledge/retriever.ts';
import { answer } from './server/knowledge/answer.ts';

const index = buildKnowledgeIndex('knowledge');        // ⭐ الفهرس

const hits = retrieve(index, 'كيف أُسند محادثة إلى موظف؟');
// ⭐ hits[0].chunk.source = { file, title, section, line, endLine, locator }

const result = answer(index, 'كيف أُسند محادثة إلى موظف؟');
// ⭐ result.status  = 'answered' | 'refused'
// ⭐ result.text    = نصّ المقطع حرفياً + سطر المصدر
// ⭐ result.sources = المصادر المعلنة
// ⭐ عند الرفض    = result.text === 'لا إجابة في الفهرس' و result.sources = []
```

⭐ **السطح العام**: `server/knowledge/index.ts` ⇒ تصدير كل حاجة + `KNOWLEDGE_DIRECTORY` (مجلد `knowledge/` جذر المشروع) + `buildDefaultKnowledgeIndex()`.

## ⭐ ١٢. حدود ما في هذا الملف

⭐ **مواصفة ووحدة شغّالة** ⇒⇒ **مش** نظام معرفة كامل للمنتج ⇒⇒ لأن:
- ⭐ مفيش نقطة دخول في السيرفر (مواصفة في §٦).
- ⭐ مفيش تحديث دوري (قرار المالك).
- ⭐ مفيش عزل على مستوى الشركة في الكود (بنية المجلد جاهزة بس).
- ⭐ مفيش قياس جودة الردود (وهي بند منفصل).
⭐ **وكل ما في الملف ده مُثبت باختبار عدّا** ⇒⇒ ⇒ ⇒ **وما فيش نسبة ولا رقم جاهزية مكتوب هنا**.
